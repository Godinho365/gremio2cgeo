# Contexto

## Objetivo
Criar uma plataforma de gestão patrimonial com agenda inteligente.

## Diferencial
Cada patrimônio possui uma agenda própria.

Fluxo:
Pesquisar -> Reservar -> Aprovação -> Cautela -> Devolução -> Inspeção

## Perfis
- Administrador
- Diretor Patrimonial
- Inventariante
- Usuário
- Auditor

## Agenda
Visualização diária, semanal e mensal.
Reserva semelhante a sistemas de barbearia.
